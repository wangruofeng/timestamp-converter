# 时间戳转换工具

一个纯前端的单文件时间戳工具，双击 `index.html` 即可使用，无需安装、无需后端、无任何外部依赖。

## 功能特性

- ⏱️ **当前时间**：大字显示当前秒级/毫秒级时间戳与本地时间，每秒跳动；支持暂停/继续；点击时间戳即可复制。
- 🔍 **自动识别单位**：粘贴时间戳后自动判断 10 位秒、13 位毫秒、16 位微秒、19 位纳秒（截断到毫秒）。
- 🌍 **多时区输出**：本地时间、UTC、东京、纽约、伦敦，以及 ISO 8601 与中文相对时间（如“3 天前”“2 小时后”）。
- 🕒 **时间 → 时间戳**：选择日期时间并指定本地或 UTC，即时输出秒级/毫秒级时间戳。
- 📋 **批量转换**：每行一个时间戳，输出对齐表格；无效行红字标注“无法识别的时间戳”，一键复制 TSV。
- 🌙 深浅色主题切换，自适应移动端。

## 使用方式

直接用浏览器打开 `index.html` 即可：

```bash
open index.html        # macOS
# 或拖入浏览器
```

## 技术说明

- 单一 HTML 文件，原生 HTML / CSS / JavaScript，零依赖、零构建步骤。
- 所有解析与转换均在浏览器本地完成，不上传任何数据。
- 日期格式化使用原生 `Intl.DateTimeFormat` API。
